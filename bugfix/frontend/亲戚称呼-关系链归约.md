# 亲戚称呼：爸爸的妈妈的丈夫算不出爷爷

## 原因
旧逻辑只做「关系链字符串 → 词典」直查，没有语义归约。  
`父→母→夫` 不在词典里，就会显示「暂未收录」。

## 修复
在 `utils/relative.js` 增加 **二元关系链归约引擎**（反复改写至不动点），例如：

| 规则 | 含义 |
| --- | --- |
| 母夫 → 父 | 妈妈的丈夫 = 爸爸 |
| 父妻 → 母 | 爸爸的妻子 = 妈妈 |
| 夫妻 / 妻夫 → ∅ | 回到自己 |
| 兄父 → 父 | 哥哥的爸爸 = 爸爸 |
| 子妻夫 → 子 | 儿媳的丈夫 = 儿子 |

因此：`父→母→夫` ⇒ `父→父` ⇒ **爷爷**。

## 验证
```bash
node life-tools-miniprogram/scripts/test-calcs.js
```
关键用例：`['父','母','夫'] → 爷爷`、`['父','父','妻'] → 奶奶`。
