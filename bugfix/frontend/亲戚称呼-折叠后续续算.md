# 亲戚称呼：折叠后继续从折叠人起算

## 需求
如「爸爸→妈妈→丈夫」折叠为「爷爷」后，再选「儿子」应得到「爸爸 / 伯伯 / 叔叔」，而不是错误的「堂兄弟」。

## 实现
1. 每次点选后 `normalizePathKeys`：把路径归约成最短标准链，栏位同步缩短
2. 栏位文案用 `progressiveLabels`（如 父父 → 显示「爷爷」）
3. 修正词典：`父父子` = `爸爸 / 伯伯 / 叔叔`（原误标为堂兄弟）
4. 提示「已折叠为某某，后续从此人继续算」
