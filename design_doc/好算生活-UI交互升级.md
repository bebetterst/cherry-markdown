# 好算生活 · UI / 交互升级说明

## 二次改造（去 emoji / 反平铺）

- 全站图标改为 `assets/icons` 线型 PNG，不再用 emoji 当主图标  
- 首页改为单列大列表，取消双列平铺卡片  
- 亲戚称呼改为「面包屑路径 + 分组全宽列表 + 底部 Dock」分步钻取  
- 倒数日符号改为图标选择器  

## 设计目标

在微信小程序原生框架内，吸收：

- **微信官方**：清晰层级、用完即走、结果可分享、触控热区充足  
- **苹果 HIG**：大标题层级、留白、即时反馈、减少无噪声  
- **抖音/热门工具小程序**：首屏效率、最近使用、结果页强分享、微动效确认完成  

服务业务目标：**更好用 → 更愿回来（留存）→ 更多结果分享（增长）**。

## 视觉方向：「青竹账本」

| Token | 值 | 用途 |
| --- | --- | --- |
| Brand | `#0B3D32` | 主色、导航、主按钮 |
| Brand Mid | `#1A6B55` | 渐变、结果卡 |
| Accent | `#E0A106` | 倒数日紧急感、关键数字 |
| Ink | `#14241F` | 正文 |
| Mute | `#6A7A72` | 次要信息 |
| Soft | `#E7F0EB` | 控件底、分段未选中 |
| Canvas | 雾绿径向渐变 + 细网格纹理 | 氛围，避免一片死灰白 |

避免：紫系渐变、奶油纸+陶土红套路、过量圆角胶囊堆叠、多层炫光阴影。

## 交互原则（留存向）

1. **继续上次**：首页展示最近使用工具，降低再次启动成本  
2. **最近倒数日**：倒数日 Tab 首屏突出最近一件事（情绪锚点）  
3. **算完即反馈**：轻触感 + 结果卡入场动效 + 主分享按钮  
4. **少即是多**：首屏只保留品牌 + 一句价值主张 + 搜索；工具列表在第二屏  
5. **热区与态**：可点元素 `active` 压暗/微缩；主按钮高度 ≥ 88rpx  

## 动效清单（≥3）

1. 页面内容轻微上浮入场（`fade-rise`）  
2. 计算结果卡弹入（`result-pop`）  
3. 工具/芯片按压缩放（`pressable`）  
4. 倒数日数字轻微呼吸（`pulse-soft`，仅最近一条）
